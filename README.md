# hedefelektrikuydu.com — yayın dosyaları

Bu depo otomatik üretilir; elle değiştirmeyin. Yalnız sitede zaten herkese açık olan dosyaları içerir
(sayfalar, görseller, yazı tipi). Sunucu bu depodaki yeni sürümü birkaç dakika içinde kendisi çeker;
imzası tutmayan sürümü uygulamaz. Kaynak dosyalar ve üretim betikleri ayrı, gizli bir depodadır.

Yazı tipi: Plus Jakarta Sans (SIL Open Font License 1.1, `assets/fonts/OFL.txt`).
